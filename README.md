# 横浜国立大学 OpenAI Student Collective の告知ページ

2026年12月4日（金）のワークショップとStudio Sessionを知らせるページです。OpenAI Student Collectiveの活動として、横浜国立大学のCampus Leadが企画・運営しています。OpenAIが直接主催する行事や、大学の公式行事ではありません。

公開先：https://rasokiwayami.github.io/ynu-collective/

## 中身

ビルドのない静的なページです。`index.html` をブラウザで開くか、このフォルダを静的なサーバーで配ると動きます。

- 会話の画面のあとに出る分子の模型は、[てのひら分子](https://github.com/rasokiwayami/molecule-viewer) を枠（iframe）で表示しています。
- 会話の文は、てのひら分子を作ったときの変更の履歴をもとに書き起こしたもので、実際の会話の記録ではありません。

## 素材

- 効果音：Kenney「Interface Sounds」（CC0）
- 分子の構造：PubChem
- 花のマークはOpenAIのものです。
